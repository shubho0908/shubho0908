## projects

### ai & systems

- **[edward](https://youtu.be/zIBuOmr92_s)** ([github](https://github.com/pragnya-works/edward)) - code execution engine with postgres advisory lock admission, append-only event stream replay, isolated docker sandboxes, and cloudflare preview routing.
- **[agentic chat](https://agentic.shubhojeet.com)** ([github](https://github.com/shubho0908/agentic-chat)) - langgraph agent loop with postgres checkpointing, pgvector hybrid search, cohere rerank, and approval-gated connector mutations.

### developer tools & infrastructure

- **[fieldcraft](https://fieldcraft.shubhojeet.me)** ([github](https://github.com/shubho0908/fieldcraft)) - chrome mv3 side-panel extension for page parsing, local company lookup, and user-approved form filling with zero telemetry.
- **[deployninja](https://youtu.be/-E-A0wyCeeE)** ([github](https://github.com/shubho0908/deployninja)) - github-triggered deployment pipeline: docker container builds on ecr, real-time log streaming via kafka to clickhouse, and ecs rolling updates.

### media & workspaces

- **[inkdown](https://inkdown.shubhojeet.com)** ([github](https://github.com/shubho0908/inkdown)) - markdown workspace using recursive postgres ctes for folder hierarchies, scroll-synced editor preview, and cloudflare r2 storage.
- **[intellect ai](https://youtu.be/QKx_BKJQ9tw)** ([github](https://github.com/shubho0908/intellect-ai)) - async image and video generation pipeline with worker polling across replicate models, mongodb queues, and cdn caching.
- **[video platform](https://youtu.be/CJEoNpLgRRw)** ([github](https://github.com/shubho0908/youtube-clone-mern)) - video hosting architecture supporting 100mb chunked resumable uploads, firebase storage integration, and mongodb engagement trees.
